# Security Policy

## Supported Version

Security fixes are applied to the latest published version of atshift Semantic Deterrence.

## Reporting a Vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/at-shift/atshift-semantic-deterrence/security/advisories/new). Do not include secrets, personal data, raw production requests, or public exploit details in a GitHub issue.

Include the affected version, prerequisites, reproduction steps, impact, and any suggested remediation. Reports that distinguish the plugin's semantic-deterrence layer from the site's WAF, web server, and WordPress access controls are especially helpful. Hub reports should identify whether the issue affects participant authentication, site ownership, privacy thresholds, aggregate integrity, revocation, caching, or deployment configuration.

We will acknowledge the report, reproduce it where possible, and coordinate remediation and disclosure. Please allow time for a fix before public discussion.

## Research Safety

Only test sites and infrastructure you own or have explicit permission to assess. This project does not authorize probing third-party systems.
